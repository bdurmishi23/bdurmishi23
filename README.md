### 👋 About Me

I'm a recently graduated **Software Engineer (BSc, Epoka University, Tirana)** interested in backend development, full-stack systems, and clean architecture.

My work ranges from **OCR/document processing** research to **Spring Boot backend systems** and modern web applications. Right now I'm building the launch site for an architecture studio.

I like building things that are precise, practical, and actually used by someone.
